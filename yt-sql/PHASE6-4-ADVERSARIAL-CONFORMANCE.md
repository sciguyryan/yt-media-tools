# Phase 6.4: seeded lexical torture checks

The `torture_metamorphic.py` runner subjects every approved portable query to deterministic seeded keyword-case and existing-whitespace perturbations. The runner executes the baseline and each variant against the **independently authored normative expectation**. It neither writes expectations nor treats agreement with the implementation as a substitute for normative review. Its random streams are reproducible by case ID, seed and variant index, so failures can be repeated without relying on corpus traversal order.

Run `python yt-sql/torture_metamorphic.py --seed 6404 --variants 4` for the complete current corpus. Use `--case statement.left_join_no_match` to isolate a failure, `--variants 32` for deeper lexical stress and `--json` for machine-readable evidence. Each variant preserves quoted literals, quoted identifiers, parameter names, source names and punctuation. The transformations are deliberately conservative: they do not assert that arbitrary SQL rewrites, comment injection, operator substitution or altered parentheses preserve meaning.

The new runner extends, rather than replaces, the earlier Phase 5 transport metamorphic checks. It establishes an adversarial regression mechanism and a reproducible seed contract. It does **not** complete the agreed Phase 6.4 obligations for grammar-aware malformed-query fuzzing, shrinking, relational algebra, nested query stress, or error-path torture; those remain required before Phase 6 certification. The corpus remains authoritative only for its independently reviewed admitted cases.
