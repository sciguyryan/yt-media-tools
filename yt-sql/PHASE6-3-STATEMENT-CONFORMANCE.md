# Phase 6.3: statement and relational conformance

This increment adds 29 independently specified, approved portable statement cases under `cases/statement-conformance/`. Their expected rows are derived from the fixed `python-v6-small` fixture's documented 60-row sequence, four equally represented `fixture_group` values and the explicitly selected source-index ranges, rather than copied from an engine execution. The cases cover projection and aliases, predicates, Boolean composition, ordering, pagination, DISTINCT, grouping and aggregate projections, common table expressions, UNION and UNION ALL, inner and left joins, CTE/join and CTE/UNION composition, and unsupported syntax and clause-order errors.

All 283 approved corpus cases passed the Python conformance adapter in this increment. That establishes compatibility with these reviewed examples, not complete semantic or cross-platform certification. The six exploratory candidates involving INTERSECT, EXCEPT, COUNT(DISTINCT), filtered grouping, HAVING and LIMIT 0 were deliberately not admitted because their initially proposed expectations did not match the adapter or its error classification. They require independent semantic adjudication, not expectations mechanically rewritten to match Python. No legacy semantic tests are retired by this increment.

Remaining Phase 6 work must exhaustively resolve these and other statement and relational contracts, including compound precedence and grouping, join multiplicity and NULL extension, grouping/aggregate corner cases, clause validation, ordering ties, parameter interactions, negative diagnostics and cross-platform equivalence. Phase 6.4 adds adversarial and torture evidence, Phase 6.5 completes justified semantic-test migration, and Phase 6.6 performs the exhaustive evidence audit and certification. Passing the current corpus does not satisfy those exit criteria.
